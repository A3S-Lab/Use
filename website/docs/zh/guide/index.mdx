# 快速开始

A3S Use 是 A3S 生态的 **AI Native Package Manager**。它不替代 `apt`、Homebrew 或 WinGet，而是管理参与 A3S 能力与安全模型的原生工具和认知插件。

## 当前可用范围

| 能力                                                         | 状态                                                  |
| ------------------------------------------------------------ | ----------------------------------------------------- |
| 本地目录与有界归档安装                                       | v0.2 可用                                             |
| Release 摘要审查与 TUF Registry                              | v0.2 可用                                             |
| 具名 Registry 替换、启用、停用、移除与刷新                   | 由 umbrella host 提供                                 |
| 原生 CLI、标准 MCP、内容绑定 Skill                           | v0.2 可用                                             |
| schema-v3 Tool、MCP、OKF、Flow、Skill、UI 合约               | `main` 已实现控制面基线                               |
| schema-v3 SemVer 依赖解析、精确 lock 与图生命周期            | signed remote standalone CLI 已可用                   |
| schema-v3 package commit/remove 与 capability 发布/隐藏/排空 | P0 generation-bound host 已实现                       |
| OKF（Open Knowledge Format）知识表面                         | M0K-C-A lifecycle adapter 已就绪，生产后端待接入      |
| A3S Flow 工作流表面                                          | Code CLI/TUI/Web 本地持久 runtime 与热插拔 E2E 已就绪 |
| 完整 Plugin Manager apply saga 与生产产品集成                | 开发中                                                |

认知插件合约、dependency resolver/lock/graph coordinator 与 P0 package/capability host 已进入 `main`。signed remote schema-v3 record 会从 `a3s-use install` 和兼容的 remote `component install` 进入同一图生命周期。Umbrella host 已提供稳定名称 Registry 替换与启停；A3S Code 已组合真实 Flow preflight host，解析精确 `flow.json` 身份，并让 CLI、TUI 与 Web 共用 workspace-local 持久 runtime。生产 grant/Knowledge/Service/Gateway 组合、分布式 Flow 调度/恢复、retention 与旧 generation 退休仍在收口。没有精确的 promoted Knowledge evidence，OKF 表面不会发布。生产部署前请以 [路线图](./roadmap) 为准。

## 安装发布版

推荐通过 A3S CLI 安装完整、已验证的发布包：

```bash
a3s install use --source release
a3s use doctor --json
a3s use capabilities --json
```

预构建归档也发布在 [GitHub Releases](https://github.com/A3S-Lab/Use/releases)。请保持归档中的二进制、Skills、Dashboard、模型资产、许可证和 provenance 文件完整；单独复制 facade binary 不是完整产品表面。

## 试用内置能力

渲染网页并将结果写入本地文件：

```bash
a3s use browser render https://example.com --output page.html
```

使用本地 OCR 并返回 JSON：

```bash
a3s use ocr extract ./scan.png --json
```

查看不可变能力快照：

```bash
a3s-use capability snapshot --json
```

## 安装认知包

通过 umbrella Plugin Manager 执行经过审查的用户生命周期：

```bash
a3s plugin search research
a3s plugin inspect acme/research
a3s plugin install acme/research --channel stable
a3s plugin upgrade acme/research
a3s plugin uninstall acme/research
```

standalone engine 也可以从显式、由宿主选择的 Registry 一次安装 signed package 及其完整 SemVer 依赖闭包：

```bash
a3s-use install acme/research \
  --registry-name packages \
  --registry-url https://packages.example.org/a3s/ \
  --trust-root sha256:<64-hex-digits> \
  --version 2.0.0 \
  --json

a3s-use uninstall acme/research --json
```

应用单独审查过的解析结果时，增加 `--package-lock-digest sha256:<64-hex-digits>`。lock 漂移会在下载任何 archive 之前失败。Runtime Service、HTTP MCP、Flow 与 OKF package 需要 embedding host 显式提供 Runtime/Gateway、A3S Flow 或 A3S Knowledge lifecycle factory。

## 从源码构建

需要 Rust 1.85 或更高版本：

```bash
git clone https://github.com/A3S-Lab/Use.git
cd Use
cargo build --workspace --bins --locked
./target/debug/a3s-use doctor --json
```

开发检查必须在 Use 仓库内运行：

```bash
cargo fmt --all -- --check
cargo test --workspace --all-features --locked
cargo clippy --workspace --all-targets --all-features --locked -- -D warnings
```

## 安装本地包

未签名的本地目录、`.tar.gz`、`.tgz` 或 `.zip` 需要明确授信：

```bash
a3s-use component install acme/calendar \
  --from ./calendar-package \
  --allow-unsigned \
  --json

a3s-use component status calendar --json
a3s-use extension disable acme/calendar --json
a3s-use extension enable acme/calendar --json
a3s-use component uninstall calendar --json
```

包 ID 是稳定生命周期身份，route 只是展示和分发别名。A3S Use 保留原生 `argv`、stdin、stdout、stderr、退出状态和标准 MCP，不添加通用 action envelope。
