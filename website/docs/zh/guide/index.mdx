# 快速开始

A3S Use 是 A3S 的 **AI Native Package Manager**，用于解析和管理原生能力，
以及包含 Tool、MCP、OKF、A3S Flow、Skill、UI 的版本化认知包依赖图。

:::caution 开发预览
A3S Use 尚未发布受支持的产品版本，也未达到 production-ready。当前仅适合
从源码构建后进行开发和评估。仓库 tag、内部 schema 编号或单元测试通过都不
代表产品已经发布。
:::

## `main` 已实现什么

| 领域         | 当前实现                                                                                |
| ------------ | --------------------------------------------------------------------------------------- |
| 包格式       | Manifest v3、六类命名表面、必需的包 README                                              |
| 依赖         | 有界 SemVer 解析、精确 Registry/TUF lock、前向准备、一次切换、反向退休                  |
| 信任         | 可替换的宿主持有 Registry 与完整 catalog-v3 provenance                                  |
| 生命周期     | install、upgrade、uninstall、enable、disable 统一走不可变 plan-v4 审查/apply            |
| 本地表面宿主 | Tool Task、stdio MCP、Skill/UI projection、SQLite/FTS5 OKF、注入式 `a3s-flow` preflight |
| 托管宿主     | Runtime Service、HTTP MCP/Gateway、托管 Knowledge/UI 组合仍在开发                       |
| 平台         | Linux/macOS 开发门禁；Windows 仍是预览检查，不是发布级一致性                            |

当前只接受一条预览协议基线：manifest v3、catalog v3、receipt v3、plan v4、
host protocol v4、manager tools v3、pending graph v2，以及 enablement
state/operation v2。过时的预览状态会被拒绝，并提示清理后重新安装。

## 从源码构建

需要 Rust 1.85 或更高版本：

```bash
git clone https://github.com/A3S-Lab/Use.git
cd Use
cargo build --workspace --bins --locked
./target/debug/a3s-use doctor --json
./target/debug/a3s-use capability snapshot --json
```

在 Use checkout 内运行仓库门禁：

```bash
cargo fmt --all -- --check
cargo test --workspace --all-targets --locked
cargo clippy --workspace --all-targets --all-features --locked -- -D warnings
```

## 试用开发版 CLI

standalone CLI 可以从显式、由宿主选择的 Registry 解析一个签名包及其完整
SemVer 依赖闭包：

```bash
a3s-use install acme/research \
  --registry-name packages \
  --registry-url https://packages.example.org/a3s/ \
  --trust-root sha256:<64-hex-digits> \
  --version 2.0.0 \
  --json

a3s-use upgrade acme/research \
  --registry-name packages \
  --registry-url https://packages.example.org/a3s/ \
  --trust-root sha256:<64-hex-digits> \
  --json

a3s-use uninstall acme/research --json
```

应用单独审查过的解析结果时增加
`--package-lock-digest sha256:<64-hex-digits>`。lock 漂移会在下载 archive
前失败。以上 Registry 值仅用于说明；项目当前没有宣传公共生产 Registry。

对已经精确 promoted 的 OKF projection 执行带引用搜索：

```bash
a3s-use knowledge search "retrieval policy" --limit 5 --json
```

Runtime Service、HTTP MCP、Flow、Knowledge、Skill、UI 的 readiness 都依赖
embedding host 显式提供 owner。owner 缺失时直接 fail closed，不会替换为宽松
runner 或 source-only binding。

## 为什么现在没有一键安装脚本

跨平台一键安装器属于首个受支持版本的发布门禁。它必须在 Linux、macOS、
Windows 上安装带 checksum、签名、SBOM、provenance、license 和完整资产的
可复现归档。在这些产物和平台门禁完成前发布便利脚本，会制造一个虚假的
产品发布入口。
